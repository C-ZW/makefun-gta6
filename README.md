**Low Tide FM** is an original crime game set in the harbor city of Port Sable. You steal a payroll tape and choose its fate: broadcast it on a pirate radio station, or sell it and send the only copy out on the ferry. A harbor patrol chases you, loses sight, searches the last corner it saw you, and can spot you again before the heat clears.

Controls: WASD or arrows to move and drive, F to interact, E to change vehicle, Space for the handbrake.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
